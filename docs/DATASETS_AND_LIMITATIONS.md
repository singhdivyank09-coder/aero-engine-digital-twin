# Datasets, Provenance & Limitations — Aero Engine Digital Twin

## 1. Dataset Provenance & Data Sources

The **Aero Engine Digital Twin — Demo Prototype** utilizes a hybrid dataset strategy combining open public benchmark datasets with physics-constrained synthetic telemetry:

### 1.1 NASA C-MAPSS Turbofan Degradation Dataset (FD001)
- **Source**: NASA Prognostics Center of Excellence (PCoE).
- **Usage**: Used strictly for benchmarking deep learning Remaining Useful Life (RUL) LSTM prognostics algorithms.
- **Role in Demonstration**: Serves as an **experimental analogue** model to demonstrate prognostics UI indicators and sequence cycle countdowns.

### 1.2 Synthetic Aero-Piston Telemetry Generator
- **Source**: In-house 10Hz physics-based telemetry simulator (`backend/telemetry_simulator.py`).
- **Target Platform Specification**: Rotax 914 / 4-cylinder 4-stroke turbocharged aircraft engine baseline curves.
- **Generated Parameters**: RPM, Manifold Pressure, CHT 1–4, EGT 1–4, Oil Pressure, Oil Temperature, Fuel Flow, Vibration RMS, Battery Voltage.

## 2. Safety & Operational Limitations

> [!IMPORTANT]
> **DEMONSTRATOR DISCLAIMER**:
> This software application is a **functional software prototype** developed by Team **Hackonauts09** for research, demonstration, and evaluation purposes only.

### Key Limitations:
1. **Simulated Telemetry**: The system operates on simulated physical engine telemetry feeds and synthetic fault injection routines. It is **not connected to an operational UAV or physical engine testbed**.
2. **Flight Certification**: This software is **not flight certified** (DO-178C / DO-254) and must not be used for real-world aviation navigation, pilot guidance, or actual flight control.
3. **Experimental RUL**: Remaining Useful Life estimates are derived from NASA C-MAPSS turbofan degradation patterns and represent an **experimental analogue metric in sequence cycles**, not a certified remaining flight hours forecast for aero-piston engines.
4. **Advisory DFCS Controls**: All Emergency Checklists, Return-to-Base (RTB) advisories, and throttle override recommendations generated by the GCS/DFCS Demonstrator are **advisory-only decision support aids** for human operators.
