# Datasets / Simulated Fault Scenarios Directory

This directory contains synthetic and simulated fault scenario logs generated by the Telemetry Simulator.

- Raw official datasets (e.g. NASA C-MAPSS FD001, ALFA flight logs) are strictly stored under `datasets/raw/`.
- Processed feature matrices are stored under `datasets/processed/`.
- Simulated aero-piston fault scenarios (thermal rise, pressure decay, misfire, sensor drift) are stored under `datasets/simulated/`.
